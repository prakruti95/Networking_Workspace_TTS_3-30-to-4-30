Section 4: Cool CMD Tricks

Matrix Effect

Command:

color 0A
tree

Creates a Matrix-like green screen effect.

Create a Folder Impossible to Delete Normally

Command:

md con\

(Teacher demo only)

Open Multiple Websites Together

Command:

start chrome
start notepad
start calc

Launches multiple applications at once.

Check Battery Health

Command:

powercfg /batteryreport

Generates battery report for laptops.

Check Wi-Fi Password

Command:

netsh wlan show profiles

Then:

netsh wlan show profile name="WiFi_Name" key=clear

Shows saved Wi-Fi password.

Teacher should explain ethical use.

Section 5: System Information Hacks

Check RAM Size

Command:

wmic memorychip get capacity

Check CPU Name

Command:

wmic cpu get name

Check BIOS Version

Command:

wmic bios get smbiosbiosversion

Check Serial Number

Command:

wmic bios get serialnumber

Check Disk Information

Command:

wmic diskdrive get model,size

Activity:
Students identify specifications of their lab PC.

Learning Outcome

Students will be able to:

* Use professional Windows shortcuts
* Navigate Windows faster
* Use Command Prompt confidently
* Find system specifications without opening settings
* Access hidden Windows tools
* Troubleshoot basic PC issues using built-in commands
