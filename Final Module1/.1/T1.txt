Day 2: Motherboard and CPU

Types of Motherboards

Motherboards come in different sizes, known as form factors.

| Type             | Size             | Common Use                        |
| ---------------- | ---------------- | --------------------------------- |
| ATX              | Standard Size    | Gaming and Desktop PCs            |
| Micro-ATX (mATX) | Smaller than ATX | Budget and Compact PCs            |
| Mini-ITX         | Very Compact     | Small Form Factor PCs             |
| E-ATX            | Larger than ATX  | Workstations and High-End Systems |

CPU Socket Compatibility

A CPU must be compatible with the motherboard socket.

| Socket Type    | Supported Processors                |
| -------------- | ----------------------------------- |
| Intel LGA 1700 | 12th, 13th, and 14th Gen Intel CPUs |
| AMD AM4        | Ryzen 1000–5000 Series              |
| AMD AM5        | Ryzen 7000 Series and Later         |

Note: A processor cannot be installed in a motherboard with a different socket type.

Functions of the CPU

The CPU (Central Processing Unit) is the main processing unit of the computer.

Main Functions:

| Function               | Description                                     |
| ---------------------- | ----------------------------------------------- |
| Instruction Processing | Executes commands from software                 |
| Calculations           | Performs arithmetic and logical operations      |
| Data Management        | Controls data flow between components           |
| System Control         | Handles tasks requested by the operating system |

Important CPU Specifications

| Specification | Meaning                                    |
| ------------- | ------------------------------------------ |
| Cores         | Individual processing units inside the CPU |
| Threads       | Virtual processing paths                   |
| Clock Speed   | Processing speed measured in GHz           |
| Cache         | High-speed memory used by the CPU          |

Functions of the Chipset

The chipset manages communication between hardware components.

| Connected Components |
| -------------------- |
| CPU                  |
| RAM                  |
| Storage Devices      |
| Graphics Cards       |
| USB Devices          |

Examples of Chipsets

| Intel Chipsets | AMD Chipsets |
| -------------- | ------------ |
| B760           | B650         |
| Z790           | X670         |

Benefits of High-End Chipsets

| Feature              | Benefit                         |
| -------------------- | ------------------------------- |
| More PCIe Lanes      | Supports more expansion devices |
| Overclocking Support | Better performance tuning       |
| More USB Ports       | Additional connectivity         |
| More Storage Options | Supports more drives            |

Day 3: RAM and Storage

1. Types of RAM

**RAM (Random Access Memory)** is temporary memory used by the CPU to store data that is actively being used.

| Type     | Speed          | Voltage | Common Use                      |
| -------- | -------------- | ------- | ------------------------------- |
| **DDR3** | 800–2133 MT/s  | 1.5V    | Older PCs                       |
| **DDR4** | 2133–5333 MT/s | 1.2V    | Most modern PCs                 |
| **DDR5** | 4800+ MT/s     | 1.1V    | Latest high-performance systems |

### Key Differences

* **DDR4 is faster and more efficient than DDR3.**
* **DDR5 offers higher bandwidth and capacity than DDR4.**
* RAM generations are **not physically compatible** with each other due to different notch positions.

### Important RAM Terms

* **Capacity:** 8GB, 16GB, 32GB, etc.
* **Speed:** Measured in MHz or MT/s.
* **Dual Channel:** Using two matching RAM sticks for improved performance.
* **Latency (CL):** Delay before data access.

---

## 2. Storage Types

### Hard Disk Drive (HDD)

An HDD uses spinning magnetic disks to store data.

**Advantages:**

* Large storage capacity
* Lower cost per GB

**Disadvantages:**

* Slower performance
* More prone to mechanical failure
* Noisy operation

### Solid State Drive (SSD)

An SSD uses flash memory with no moving parts.

**Advantages:**

* Faster boot times
* Faster file transfers
* More reliable
* Silent operation

**Disadvantages:**

* Higher cost per GB than HDDs

---

## 3. SATA SSD vs NVMe SSD

| Feature       | SATA SSD       | NVMe SSD         |
| ------------- | -------------- | ---------------- |
| Interface     | SATA           | PCIe             |
| Typical Speed | Up to 550 MB/s | 2000–14000+ MB/s |
| Connector     | SATA cable     | M.2 slot         |
| Performance   | Good           | Excellent        |

### Storage Comparison

| Type     | Speed     | Cost     |
| -------- | --------- | -------- |
| HDD      | Slow      | Cheapest |
| SATA SSD | Fast      | Moderate |
| NVMe SSD | Very Fast | Higher   |
-----------------------------------------------------
| Feature       | SATA SSD               | NVMe SSD                                          |
| ------------- | ---------------------- | ------------------------------------------------- |
| Interface     | SATA (Serial ATA)      | PCIe (Peripheral Component Interconnect Express)  |
| Typical Speed | ~500–600 MB/s          | ~2,000–14,000 MB/s (depending on PCIe generation) |
| Latency       | Higher                 | Lower                                             |
| Form Factors  | 2.5-inch, M.2          | Usually M.2, add-in cards                         |
| Cost          | Usually cheaper        | Usually more expensive                            |
| Best For      | General use, older PCs | Gaming, video editing, heavy workloads            |
