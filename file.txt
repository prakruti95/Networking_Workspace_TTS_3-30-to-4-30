# Step-by-Step IP Address Calculation

We need to find these five things for each IP address:

1. Network ID
2. Broadcast ID
3. First Usable IP
4. Last Usable IP
5. Total Usable Hosts

## Step 1: Understand the basic formulas

- Network ID: The first address of the subnet.
- Broadcast ID: The last address of the subnet.
- First Usable IP: Network ID + 1.
- Last Usable IP: Broadcast ID − 1.
- Total Usable Hosts: $2^h-2$, where $h$ is the number of host bits.

We subtract 2 because the network address and broadcast address cannot normally be assigned to hosts.

## Step 2: Learn the block size method

For subnet masks other than `/24`, use this formula:

$$
\text{Block Size}=256-\text{Mask Value}
$$

The mask value is the relevant subnet-mask octet.

| Subnet mask | CIDR | Block size | Usable hosts |
| --- | --- | --- | --- |
| 255.255.255.0 | /24 | 256 | 254 |
| 255.255.255.128 | /25 | 128 | 126 |
| 255.255.255.192 | /26 | 64 | 62 |
| 255.255.255.224 | /27 | 32 | 30 |

Now let’s solve each question step by step.

## 1. IP Address: 192.168.10.25

Subnet Mask: `255.255.255.0`

Step 1: Find the CIDR

The subnet mask `255.255.255.0` has 24 network bits.

Therefore, CIDR = `/24`.

Step 2: Find the block size

$$
256-0=256
$$

The block size is 256, so the last octet covers addresses from 0 to 255.

Step 3: Find the Network ID

The IP address is `192.168.10.25`.

Since this is a `/24` subnet, the first three octets are the network portion and the last octet is the host portion.

Set the host portion to 0:

Network ID = `192.168.10.0`

Step 4: Find the Broadcast ID

Set the host portion to 255:

Broadcast ID = `192.168.10.255`

Step 5: Find the usable IP addresses

- First Usable IP = Network ID + 1 = `192.168.10.1`
- Last Usable IP = Broadcast ID − 1 = `192.168.10.254`

Step 6: Calculate usable hosts

There are 8 host bits.

$$
2^8-2=256-2=254
$$

Final answer:

| Property | Answer |
| --- | --- |
| Network ID | `192.168.10.0` |
| Broadcast ID | `192.168.10.255` |
| First Usable IP | `192.168.10.1` |
| Last Usable IP | `192.168.10.254` |
| Total Usable Hosts | 254 |

## 2. IP Address: 192.168.10.130

Subnet Mask: `255.255.255.128`

Step 1: Find the CIDR

The subnet mask `255.255.255.128` is `/25`.

Step 2: Calculate the block size

$$
256-128=128
$$

Block size = 128.

This means the subnets in the last octet start at:

- Subnet 1: 0–127
- Subnet 2: 128–255

Step 3: Find which subnet contains the IP

The given IP is `192.168.10.130`.

Since 130 falls between 128 and 255, it belongs to the second subnet.

Therefore:

Network ID = `192.168.10.128`

Step 4: Find the Broadcast ID

The last address in the range 128–255 is 255.

Broadcast ID = `192.168.10.255`

Step 5: Find the usable IP addresses

- First Usable IP = `192.168.10.128 + 1` = `192.168.10.129`
- Last Usable IP = `192.168.10.255 − 1` = `192.168.10.254`

Step 6: Calculate usable hosts

A `/25` subnet has $32-25=7$ host bits.

$$
2^7-2=128-2=126
$$

Final answer:

| Property | Answer |
| --- | --- |
| Network ID | `192.168.10.128` |
| Broadcast ID | `192.168.10.255` |
| First Usable IP | `192.168.10.129` |
| Last Usable IP | `192.168.10.254` |
| Total Usable Hosts | 126 |

## Easy trick to remember for exams

1. Find the CIDR from the subnet mask.
2. Calculate block size: `256 − subnet mask value`.
3. Find the range containing the given IP.
4. The first address of the range is the Network ID.
5. The last address of the range is the Broadcast ID.
6. Add 1 to the Network ID and subtract 1 from the Broadcast ID to find usable IPs.
7. Calculate usable hosts using $2^{32-\text{CIDR}}-2$.
